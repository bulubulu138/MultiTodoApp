### v1.1.0 性能优化版重点改进：

- ✅ **搜索响应 < 200ms**（支持 1000+ 任务毫秒级搜索）
- ✅ **周报生成 < 500ms** + 智能任务质量评分
- ✅ **双视图模式**（卡片浏览 + 沉浸式内容专注）
- ✅ **独创任务关联系统**（依赖 / 背景 / 并列 3 大关系）
- ✅ **强大富文本编辑器**（图片粘贴 + 拖拽上传）
- ✅ **可选 AI 智能辅助**（100% 可禁用）
- ✅ **全局快捷键** `Ctrl/Cmd + Shift + T`（一键创建任务）
