## 🛠️ 技术架构

<details>
<summary><strong>点击展开</strong> - 了解 MultiTodo 的技术底座</summary>

### 核心技术栈
- **前端**：React 18 + TypeScript + Ant Design 5
- **桌面应用**：Electron 27（跨平台原生体验）
- **本地存储**：SQLite + better-sqlite3（性能优化）
- **富文本编辑**：Quill 2.0 + 图片上传
- **虚拟化渲染**：react-window（1000+ 条任务无压力）

### 架构亮点
✅ **100% 本地存储**：所有数据存储在本地，无云端依赖  
✅ **性能优化**：虚拟化渲染 + 数据库索引 + LRU 缓存  
✅ **安全可靠**：内容哈希防重复 + 自动备份  
✅ **跨平台原生**：Windows + macOS 完美适配  

### 数据库设计
采用规范化设计，支持复杂关系：
- `todos` - 任务主表（支持富文本、标签、优先级）
- `todo_relations` - 任务关系表（依赖、背景、并列）
- `flowcharts` - 可视化工作流
- `notes` - 工作反思笔记

</details>

## 🛠️ 开发指南

欢迎贡献代码！请确保你的开发环境满足以下要求。

### 📋 环境要求
- **Node.js** >= 20.x
- **Python** 3.11+（仅 macOS 图标生成需要）
- **Git** 最新版本

### 🚀 开发流程

```bash
# 1. 克隆项目
git clone https://github.com/bulubulu138/MultiTodoApp.git
cd MultiTodoApp

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev              # 启动完整开发环境（主进程 + 渲染进程）
npm run dev:main         # 仅编译主进程
npm run dev:renderer     # 仅启动渲染进程开发服务器

# 4. 构建应用
npm run build            # 构建应用
npm run dist             # 打包成安装包
npm run dist:win         # 仅打包 Windows
npm run dist:mac         # 仅打包 macOS
```

### 📦 版本发布

```bash
# 自动递增补丁版本（1.1.0 → 1.1.1）
npm run release

# 发布指定版本
npm run release 1.2.0
```

发布脚本自动完成：
1. ✅ 更新版本号
2. ✅ 创建 git tag
3. ✅ 推送到 GitHub
4. ✅ 触发 GitHub Actions 自动构建

### 📚 项目结构
```
src/
├── main/              # Electron 主进程
│   ├── main.ts        # 应用入口
│   ├── preload.ts     # IPC 安全桥接
│   ├── database/      # SQLite 数据层
│   └── services/      # 业务服务层
└── renderer/          # React 渲染层
    ├── App.tsx        # 主应用组件
    ├── components/    # React 组件
    └── hooks/         # 自定义 hooks
```

### 💡 开发建议
- 使用 TypeScript 编写代码
- 遵循 ESLint 规则
- 为重要功能编写单元测试
- 大的 PR 请提前讨论
