# 专注模式工具栏与浮层层级修复设计

## 目标

修复专注模式中的两个交互问题：

1. 滚动进入某个待办后，即使继续滚动到该待办内容很深的位置，待办工具栏仍固定在专注模式滚动区顶部；进入下一个待办后由下一个工具栏自然接替。
2. 新增待办弹窗和待办详情抽屉始终显示在专注模式工具栏之上，避免被“查看详情”按钮遮挡。

## 设计

专注模式继续使用每个待办独立的 `position: sticky` 工具栏，并让吸顶位置、背景覆盖和层级在专注模式滚动容器内形成明确约束。工具栏的层级保持低于应用弹窗层，且滚动容器不创建会限制 sticky 的额外层叠上下文。

新增待办弹窗和详情抽屉显式使用高于专注模式工具栏的 Ant Design `zIndex`，并挂载到 `body`，确保它们不受待办项局部布局和 sticky 元素影响。

## 测试

增加 CSS 结构回归断言，验证专注模式滚动容器和工具栏的吸顶、背景及层级关系；增加源代码回归断言，验证新增待办 Modal 与详情 Drawer 都声明高于工具栏的层级并使用 body 挂载。

## 非目标

不修改待办数据模型、滚动数据流、编辑器保存逻辑或数据库层。
